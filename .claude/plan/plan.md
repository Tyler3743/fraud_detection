Giờ đọc pretrain_gnn.py và train_gnn.py để chốt hai bước huấn luyện cuối.Dựa trên code thực tế trong `ct551_v2` (đã đọc `temporal_split_index.py`, `feature_edge.py`, `feature_node.py`, `build_graph.py`, `node_seq.py`, `assemble_txn.py`, `pretrain_gnn.py`, `train_gnn.py`), pipeline chạy tuần tự như sau:

| #   | File                                                             | Input                                                                               | Làm gì                                                                                                                                                                                                                                                   | Output                                                                                                         |
| --- | ---------------------------------------------------------------- | ----------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------- |
| 1   | `temporal_split_index.py`                                        | `HI-Small_Trans.csv`                                                                | Sắp theo Timestamp, gán nhãn train/val/test theo mốc 60/20/20                                                                                                                                                                                            | `HI-Small_Trans_split_index.csv`                                                                               |
| 2   | `feature_edge.py` (gọi `load_data()` của `feature_node.py`)      | file ở bước 1                                                                       | Tính đặc trưng cạnh theo cửa sổ trượt 6h (deg, fan-in/out, số tiền, số cặp lặp, tỷ lệ đổi ngân hàng/tiền tệ) cho từng cặp (src, dest); chuẩn hoá log1p + StandardScaler                                                                                  | `edge_attr_{train,val,test}.parquet`                                                                           |
| 3   | `build_graph.py`                                                 | file bước 1 + `edge_attr_*.parquet`                                                 | Gán index node dùng chung cho cả 3 split, dựng 3 đồ thị PyG lũy tiến (train ⊂ val ⊂ test, có thêm cạnh ngược)                                                                                                                                            | `graphs.pt`, `txn_nodes.npy` (map mỗi giao dịch → node nguồn/đích)                                             |
| 4   | `node_seq.py`                                                    | file bước 1 + `txn_nodes.npy`                                                       | Cắt 6h đầu train thành `train_a`/`train_b` (tránh leak), gom hoạt động mỗi node theo bucket 90 phút (K=4 bucket gần nhất): số lần, tổng tiền, số đối tác, tỷ lệ cross-bank/currency                                                                      | `node_seq_{train,val,test}.npy`, `train_b_mask.npy`                                                            |
| 5   | `feature_transaction.py` + `feature_node.py` + `assemble_txn.py` | file bước 1                                                                         | Trích đặc trưng giao dịch (30 cột) và đặc trưng tài khoản (63 cột), ghép lại thành bảng phẳng kèm nhãn — dùng làm đầu vào phụ cho Head và để lấy số chiều `tx_dim`                                                                                       | `txn_matrix_{train,val,test}.parquet`                                                                          |
| 6a  | `train_gnn.py`                                                   | `graphs.pt`, `node_seq_*.npy`, `txn_matrix_*` (lấy tx_dim + nhãn)                   | Huấn luyện **có giám sát**: EdgeSAGE (2 lớp, message passing có/không đặc trưng cạnh) + LSTM mã hoá `node_seq` → Head dự đoán nhãn giao dịch. Chỉ train trên `train_b`. 2 biến thể (`sage_lstm`, `sage_noedge_lstm`) × 4 seed, chọn theo PR-AUC trên val | `winner-v3.json`, `variant_board-v3.csv`, điểm dự đoán `.npy` trong `scores/`                                  |
| 6b  | `pretrain_gnn.py`                                                | `graphs.pt`, `node_seq_*.npy`, `txn_matrix_*` (chỉ lấy tx_dim, **không** dùng nhãn) | Huấn luyện **tự giám sát**: chia cạnh train thành 3 rổ (85% truyền tin / 10% giám sát link / phần còn lại dừng sớm), học bằng link prediction (BCE, negative sampling theo bậc node). 2 biến thể × 4 seed                                                | `emb_{tag}_seed{seed}_{split}.npy` (embedding node mỗi split) trong `scores/emb-ssl/`, `pretrain_board-v3.csv` |

Hai nhánh cuối (6a, 6b) dùng chung dữ liệu đồ thị nhưng phục vụ hai mục đích khác nhau: `train_gnn.py` tự nó là kết quả "nhóm 2" trong luận văn (GraphSAGE+LSTM đánh giá độc lập), còn `pretrain_gnn.py` chỉ sinh embedding để `train_hybrid.py` dùng làm đặc trưng bổ sung cho nhóm 3 — chứ hai file này không gọi lẫn nhau ngoài việc `pretrain_gnn.py` import `DEV, HID, Model` từ `train_gnn.py` để dùng chung kiến trúc mạng.
